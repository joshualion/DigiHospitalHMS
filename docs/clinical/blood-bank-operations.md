# Blood Bank Operations

Use Blood Bank from the admin sidebar when the user has `blood-bank.view`.

## Configuration

Configure blood-bank locations, storage units, donor categories, component types and screening tests before operational use. Seeded records are structural examples only.

## Workflow

1. Register the donor and record consent.
2. Record manual screening responses and eligibility decision with a reason.
3. Schedule an optional donation appointment.
4. Record collection. The system assigns donation and bag numbers and keeps the unit quarantined.
5. Enter blood group/Rh and have another authorized user verify it.
6. Enter configured screening results and have another authorized user verify them.
7. Prepare components. Components start in quarantine.
8. Release only after required tests are verified and manually cleared.
9. Transfer, recall or discard components with mandatory reasons.
10. Use amendments for corrections; do not overwrite verified records.

No compatibility/crossmatch, issue, transfusion, reaction or analyzer workflow is part of Phase 7A.
