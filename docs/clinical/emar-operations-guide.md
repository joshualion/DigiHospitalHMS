# eMAR Operations Guide

Use eMAR only for active admitted patients with an inpatient chart.

## Before Administration

Confirm:

- Patient.
- Medication.
- Dose.
- Route.
- Timing.

The eMAR screen shows allergy, alert, discontinued-order and stock-availability warnings where available. Staff must follow local clinical policy; the system does not provide interaction checking or dosing advice.

## Outcomes

Supported outcomes:

- Administered.
- Omitted.
- Refused.
- Held.
- Unavailable.
- Delayed.
- Not given.

Every non-administered or delayed outcome requires a reason. PRN administrations also require an indication and may include response/effect follow-up.

## Corrections

Do not delete or edit administration records. Add a correction with a reason and note. The original administration remains part of the medication history.

Unused dispensed medication should be handled through the existing pharmacy return workflow.
