# Procurement And Receiving Guide

1. Create active suppliers and link the inventory items they can supply.
2. Configure approval limits by role and currency.
3. Draft a requisition from the destination inventory location.
4. Submit the requisition for approval.
5. A different authorized user approves or rejects it.
6. Convert an approved requisition into a purchase order with an active supplier.
7. Post partial or full goods receipts against PO lines.
8. Enter batch number, expiry/manufacture dates, received, accepted and rejected quantities.
9. Accepted quantities post to the stock ledger. Items requiring clearance arrive in quarantine.
10. Use supplier return or receipt reversal for corrections; do not delete records or edit stock balances directly.

Over-receipt is blocked unless the user has explicit over-receipt permission and the action is audited.
