# Public Site Design System

Phase 1B uses a restrained clinical palette: slate for structure, teal for trust/action, rose for urgent appointment/contact emphasis, and cyan accents on dark surfaces. Cards use small radii, clear borders, and dense but readable spacing.

Typography uses the existing app font stack with strong section hierarchy. The homepage uses full-width bands rather than nested cards. The hero uses real project-owned imagery from `public/frontend/images` and avoids fake statistics or unverifiable care claims.

Responsive rules: header collapses to a keyboard-accessible menu, sections use one-column mobile layouts, images define dimensions, and below-fold media is lazy loaded where appropriate.
