# Public Site Media And Licensing

Phase 1B media comes from existing project-owned assets, uploaded hospital-owned files, or clearly marked placeholders. Do not hotlink random web images.

The media library accepts JPEG, PNG, and WebP images only. SVG and executable-style uploads are rejected. Uploads are MIME checked, size limited, dimension checked, stored with server-generated filenames, and audited.

Placeholder clinician/testimonial/news content is for development layout verification only and must be replaced with approved hospital-owned material before production use.
