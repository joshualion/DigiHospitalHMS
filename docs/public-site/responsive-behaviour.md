# Public Site Responsive Behaviour

Phase 1B.1 public pages are designed around stable content widths and tokenized section rhythm.

## Breakpoints Checked

- 320px mobile.
- 375px mobile.
- 390px smoke viewport.
- 430px large mobile.
- 768px tablet.
- 1024px small desktop/tablet landscape.
- 1280px desktop.
- 1440px desktop.

## Rules

- Mobile header uses an accessible slide-in navigation panel with Escape-key closing and body-scroll locking.
- Desktop navigation stays visually balanced with the appointment CTA and theme control outside the primary nav.
- Hero content is centered with constrained text width and stable minimum height.
- Information band stacks cleanly on mobile and uses a compact multi-column layout on tablet/desktop.
- Services accordion is two columns on wide screens and one column on mobile.
- Detailed prose stays left-aligned.
- Footer grids collapse without horizontal overflow.
- Theme switcher stays in the header/mobile panel and does not cover content.

## Visual Verification

The Phase 1B.1 smoke suite captures homepage variants for light/dark and all accents, plus mobile navigation, theme chooser, services accordion, admin theme settings, and draft preview.
